# Independent Reading Project: Endoscopic Vision and Surgical Scene Understanding for AI-Assisted Surgical Robotics

This repository contains a self-directed reading project on endoscopic vision, surgical scene understanding, and AI-assisted surgical robotics.

The project reviews five representative papers covering:

1. Deep learning-based endoscopic localization, mapping, and 3D reconstruction
2. Surgical instrument segmentation and tracking
3. Grounded multimodal large language models for endoscopic surgery
4. Large vision models for robot-assisted surgery
5. Multi-task surgical scene understanding benchmarks, including surgical phase recognition, instrument keypoint estimation, and instance segmentation

## Motivation

Endoscopic vision is a key perception layer for AI-assisted surgical robotics. Accurate perception of surgical scenes can support robot-assisted navigation, visual servoing, surgical decision support, and human-robot collaboration in minimally invasive procedures.
